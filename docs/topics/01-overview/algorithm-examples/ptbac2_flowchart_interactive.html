Thuật toán giải phương trình bậc hai a*x² + b*x + c = 0

Nhập a, b, c (số thực bất kỳ) rồi chạy từng bước. Bước đang xử lý tô màu cam, đường đã đi được tô đậm. Màn hình bên phải chứa mã nguồn chương trình C cài đặt thuật toán và kết quả tương ứng.

a, b, c phải là số thực. Dùng dấu chấm cho phần thập phân, ví dụ 2.5 hoặc -0.75.
